# Juego4
Juego 3: Cannon

Este repositorio contiene `cannon.py`, un videojuego desarrollado en Python utilizando la biblioteca Turtle Graphics de Free Python Games. 
El programa consiste en controlar un cañón que dispara proyectiles para golpear balones que se encuentran en movimiento dentro de la ventana del juego.

## Cambios realizados por mí

- Modifiqué la velocidad de movimiento de los proyectiles para que se desplacen más rápido.
- Aumenté la velocidad de movimiento de los balones para hacer el juego más dinámico.

## Cambios realizados por mi compañero

- Modificó el funcionamiento de los balones para que, al salir de los límites de la ventana, regresen a una posición dentro del área de juego.
- Implementó esta condición para evitar que el juego termine cuando los balones salen de la pantalla.

Estos cambios permiten que el videojuego tenga una mayor velocidad y que la partida continúe indefinidamente, 
haciendo que la experiencia de juego sea más dinámica y continua.
